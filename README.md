# Clean & Green Waste Reporting Web

A smart waste reporting application that helps users report garbage issues directly to municipality authorities using image upload and live location tracking.

## Features

- Upload garbage images
- Capture live location
- Report waste issues instantly
- User-friendly interface
- Municipality notification support

## Technologies Used

- React
- Node.js
- Firebase
- Google Maps API
- HTML
- CSS
- JavaScript

## Installation

```bash
npm install
npm start
```

## Purpose

This project helps citizens maintain a clean environment by enabling quick waste reporting through a mobile/web application.
