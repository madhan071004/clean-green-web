**Clean-Green** empowers citizens to easily report and document waste accumulation, helping to build clean, healthy, and toxic-free communities. By crowdsourcing ecological hazard data, the application bridges the gap between residents and municipal authorities.

## ✨ Key Features

- **📍 Geo-Tagged Reporting**: Pinpoint the exact location of waste using an interactive map powered by Leaflet.
- **📸 Visual Evidence**: Upload photos of ecological hazards to provide clear proof for authorities.
- **🏷️ Smart Categorization**: Route petitions to the correct departments (Municipal, Bio-medical, Electronic, Plastic & Toxic).
- **✉️ Automated Dispatch**: Generate formatted petition emails ready to be dispatched to the responsible municipal commissioners.
- **🌓 Dark/Light Mode**: User-friendly interface with support for multiple themes (Sunlight and Dark mode).
- **🏆 Gamified Eco Citizen Ranking**: Earn ranks (Apprentice, Green Citizen, Eco Warrior) and Eco Scores to encourage community participation.
- **🔔 Live Notifications & Dashboard**: Track your grievances, view community awareness feeds, and manage your profile.

## 🛠️ Technology Stack

- **Frontend Framework**: React 19 + Vite
- **Mapping**: Leaflet & React-Leaflet
- **Animations**: Framer Motion for smooth and dynamic micro-interactions
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Data Management**: LocalStorage for persistent client-side data (dummy database simulation)

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd clean-green/clean-green-web/client
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to the URL provided in your terminal (typically `http://localhost:5173`).

## 💡 How It Works

1. **Mark Site Location**: Use the interactive map to drop a pin exactly where the waste or hazard is located.
2. **Upload Photo & Details**: Add a clear photo of the debris, select the correct waste department, and describe the issue.
3. **Submit Petition**: Once filed, a grievance report is generated on your dashboard.
4. **Dispatch Email**: With one click, forward the formal petition directly to the relevant municipal authority via the automated email generator.
